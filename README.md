# APPM4600

This repo contains the completed lab work and homework from CU Boulder's Numerical Methods and Scientific Computing (APPM 4600) course.
- Any python scripts created for the homework lives in the Homework directory. 
- Any python scripts or txt files created for the Labs lives in the Labs directory.  

The topics covered in the labs are as follows:  
- Lab 1: Introduction to Python
- Lab 2: Introduction to Git

NOTE: .DS_Store has been placed in the .gitignore file so non-MacOS users don't run into it (it should theoretically be applied to all subdirectories as well). Do not remove this from the .gitignore.
